# Brew & Bean Masterpiece

Act as a senior full-stack mobile developer with 10 years of experience to build a production-ready coffee shop app called "Brew & Bean" using React Native with Expo and TypeScript, Firebase for authentication and Firestore database, Zustand for state management, and NativeWind for TailwindCSS styling. The app must include email/password and Google SSO login, a menu browsing screen with category filters and search functionality, a detailed customization flow where users can modify milk types, syrup flavors, and espresso shots with dynamic price updates, a persistent shopping cart with checkout and tax calculation, real-time order tracking with status updates like "Preparing" and "Ready for Pickup," a loyalty stamp card system granting a free drink every 5th purchase, and a profile screen showing user history and favorites. The design should use an earthy, warm color palette with coffee brown (#6F4E37) as primary, amber (#FFB347) as secondary, and off-white (#F9F6F0) as background, with Inter typography, smooth spring animations for cart interactions, and a bottom tab navigator for Home, Cart, Orders, and Profile screens. Follow clean code practices with proper error handling, accessibility labels, custom components (no external UI libraries), and a feature-based folder structure. Generate the code step-by-step, starting with project setup and Firebase configuration, then authentication, then the home screen UI and remaining features.
